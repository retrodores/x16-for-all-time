# Contributing to X16 For All Time

X16 For All Time is developed with AI coding agents. Agent-led contributions are preferred, with a human directing the work and reviewing the proposed changes. This project is set up primarily for that workflow.

## Before making changes

1. Read every applicable `AGENTS.md`, including any workspace instructions and any files under the directories you will edit.
2. Read the available handoff notes and other material that describes the current state of the program. Check the current `main` branch, the README, and the latest release notes and wiki pages relevant to your task. Carry forward decisions and known issues from the handoff.
3. Check your proposed change against the current source and behavior. When handing the work back, summarize the change, what you verified, and anything still open so the next agent can pick up the work.
