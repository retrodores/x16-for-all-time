# Contributing to X16 For All Time

X16 For All Time prefers pull requests and commits authored by AI coding agents under human guidance. The human defines the goal and scope and reviews the proposed changes.

## Before making changes

1. Read every applicable `AGENTS.md`, including any workspace instructions and any files under the directories you will edit.
2. Read the available handoff notes and other material that describes the current state of the program. Check the current `main` branch, the README, and the latest release notes and wiki pages relevant to your task. Carry forward decisions and known issues from the handoff.
3. Check your proposed change against the current source and behavior. When handing the work back, summarize the change, what you verified, and anything still open so the next agent can pick up the work.

## Commits and pull requests

- Keep each commit small enough to review on its own. Give it one clear purpose and a commit message that describes the change.
- Keep each pull request focused on a well-defined task. Break larger work into logical, reviewable commits or pull requests. Leave unrelated cleanup for separate work.
- Prefer to have a [GitHub issue](https://github.com/retrodores/x16-for-all-time/issues) describe the problem or requested change. Link that issue from the pull request when one exists.
